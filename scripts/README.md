# 脚本

| 脚本 | 用途 | 归属 |
|---|---|---|
| `self_test.sh` | 运行 `--self-test` 并解析输出 | T-014 |
| `run_fault_injection.sh` | 跑故障注入套件 | T-013 |
| `run_module_isolation.sh` | 逐个禁用非核心模块并断言自检退出码 0 | T-012 |
| `package.sh` | 生成发布包 | T-015 |

## 层出口条件也应当是脚本

任务书 §3.7 要求层出口条件必须转成「脚本 + 退出码」，否则验收只能靠人说
「我觉得可以了」。但 §41.4 的脚本清单里**没有**层出口脚本 ——
这是任务书的一处缺口，已在 T-001 的文档中标出，需要在 T-012 / T-013 时定下来。
