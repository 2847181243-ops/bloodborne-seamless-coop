## 1. 背景：机器只能查"格式与自洽"，查不了"对不对"

`docs/re/README.md` 第 2 节定义了关键函数的记录格式（10 个字段 + 版本绑定），
这个格式本身很好。缺的是**机器可校验的部分**。

需要先明确一个边界，否则会走向两个极端——要么什么都不查，
要么声称"门禁绿了所以结论是对的"。**两者都不对。**

| | 机器能查 | 只有人能查 |
|---|---|---|
| 声明了 `Confidence` 吗 | ✅ | |
| `Confidence` 取值合法吗 | ✅ | |
| `Evidence` 是空的吗 | ✅ | |
| 声明 `Confirmed` 时提到了可核对证据的一类吗 | ✅ | |
| **地址真的是那个函数吗** | | ✅ 需要运行时验证 |
| **`Purpose` 写得对吗** | | ✅ |
| **引用的反汇编是真的吗** | | ✅ |
| **`Signature` 匹配 1.09 吗** | | ✅ |

**AI-00 已经实现了机器能查的那一半**（`tools/preci/check_re_spec.py`，负例矩阵 9/9）。
剩下的只是**把这个格式写进 `docs/re/README.md`**，让写文档的人知道规则。

## 2. 需要 AI-A1 落到 `docs/re/README.md` 的内容

在第 2 节（记录格式）之后插入一小节，说明四条规则与"不查什么"。
下面是可以直接用的文本：

````markdown
## 2.1 机器校验的规则（写之前先看，否则门禁会红）

本地预检会检查每个 `### <FunctionName>` 记录。**只查机器能判断的东西**，
不假装能判断结论对不对。

| 规则 | 检查什么 | 为什么值得机器查 |
|---|---|---|
| **R-1** | `Confidence` 字段存在，且取值是四个之一 | 不写等级 ⇒ 无法区分"确认过"与"猜的"。这是最重要的一条 |
| **R-2** | `Evidence` 字段存在且**非空** | `Evidence` 空白 + `Confidence: Confirmed` 是自相矛盾的 |
| **R-3** | 若 `Confidence` 是 `Confirmed`，`Evidence` 必须提到四类证据之一：`反汇编` / `交叉引用` / `运行时` / `实验` | 堵住"没证据却敢写已确认" |
| **R-4** | 文档里至少有**一处**版本绑定块（四项齐全） | 地址不绑版本就等于没记 —— 游戏一更新全部作废且无人知道 |

**明确不查的**（避免产生"门禁绿了就等于对"的错觉）：

- ❌ 地址**是否真的是**那个函数 —— 机器无法判断，只能靠运行时验证
- ❌ `Purpose` 写得对不对
- ❌ `Evidence` 里贴的反汇编是不是真的
- ❌ `Signature` 是否与 1.09 匹配

> ⚠️ **这四条规则是"格式与自洽性"检查，不是"正确性"检查。**
> 它能让"漏写等级"和"没证据却声明已确认"变成可见的、有位置的问题；
> 它**不能**代替运行时验证。

**写法的正反例**

```markdown
<!-- ✅ 合格：等级 + 具体证据 -->
| Evidence | 反汇编 0x1400A2B10 起 40 字节，见下方片段；运行时在 Boss 死亡时断点命中 3 次 |
| Confidence | Confirmed |

<!-- ❌ 不合格（R-3）：声明已确认但证据里没有任何一类可核对的证据 -->
| Evidence | 看起来是这样 |
| Confidence | Confirmed |

<!-- ❌ 不合格（R-1）：没写等级 -->
| Evidence | 反汇编片段 |
```
````

## 3. 适用文件

校验只作用于**含函数记录**的文件：

```text
docs/re/addresses.md      函数地址与模块布局   ← 主要目标
docs/re/structures.md     结构体布局与偏移
docs/re/findings.md       汇总：结论 / 待确认项 / 证据索引
```

`docs/re/README.md` 本身是规范文档，不含记录，不参与校验。

> ⚠️ **如果 AI-A1 认为 `structures.md` 里的结构体偏移不该按"函数记录"校验**
> （它们不是函数，没有 `Confidence` 的语义），
> 请在 PR 里说明并把该文件从 `tools/preci/check_re_spec.py` 的 `RECORD_FILES`
> 里去掉。**规则可以讨论，但要有记录。**
> 当前把它列入，是因为"这个偏移量到底对不对"同样需要等级标注。
