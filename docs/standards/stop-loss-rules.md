# 止损规则（防止把时间烧在没有进展的地方）

> **为什么有这份文件**：本项目由多个 AI Agent 长时间连续作业。
> 已经实测到一种失败模式 —— **同一个问题反复尝试，每次换个小办法，直到预算耗尽才发现方向错了**。
>
> 参考来源：`build_in_harmonyos`（gitcode.com/OpenHarmonyPCDeveloper/build_in_harmonyos）
> 的 R41 / R43 / R48。它们是在数千次真实编译里磨出来的，不是设计出来的。
> 原文教训一句话：
>
> > 教训不是"不等 CI"，而是"**不裸等**"：先落草稿，再用工具轮询，红了修到绿。

---

## 1. 三条硬性止损

### SL-1 同类失败连续 5 次 → 停手，写报告

**触发**：同一个**错误类别**（不是同一行报错，而是同一类问题）
连续 5 次修复尝试都失败。

**动作**：
1. **停止修改代码**
2. 写一份简短报告：已试过什么、每次都观察到什么、为什么都没成
3. 改变**手段类别**，而不是继续换参数

**为什么**：换参数属于同一类手段。第 5 次和第 1 次的信息量几乎一样。

**实测案例（本项目自己的）**：
给门禁脚本做"编译标准是否被削弱"的检查时，我连续 4 次调整正则都没成：

| 次 | 尝试 | 结果 |
|---|---|---|
| 1 | 整文件子串匹配 | **自指**：要找的 `/WX` 也出现在断言消息里，检查永远通过 |
| 2 | 剔除注释行后匹配 | 仍是自指（断言消息不是注释） |
| 3 | 只匹配第一个 `target_compile_options` 调用 | 该文件有 4 个独立调用，只读到第一个 |
| 4 | 括号配平 | 仍只读第一个调用 |

第 5 次才跳出"改正则"这一类手段，改为**括号配平 + 累加所有调用**，立刻成功。

**如果当时有 SL-1，应该在第 3 次就停下来问："我是不是一直在换同一类手段？"**

---

### SL-2 外部依赖连续失败 3 次 / 超 30 分钟 → 记录并绕开

**触发**：网络、registry、远端 API、外部工具连续 3 次不可达，或累计超过 30 分钟无进展。

**动作**：
1. 记录确切错误（不是"网络不通"，而是完整报错）
2. 找**替代路径**或用**已有数据**继续
3. 明确标注"这一项未验证"及原因

**为什么**：外部依赖的失败**不是本项目的问题**，继续等待不会让它变好。

**实测案例**：本仓库远端 API 在本机被 MITM 拦截（Steam++/Watt Toolkit），
`api.github.com` 直连失败。处理方式是**用 `--resolve` 指定 IP 直连**，而不是反复重试。
这个替代路径已经固化成脚本。

---

### SL-3 长任务前检查预算，接近上限就收尾

**触发**：开始一个预计较长的阶段之前。

**动作**：
1. 估算这次要做什么、大概需要多久
2. 如果剩余预算不足以**完成并验证**，先选一个能完成的小目标
3. 接近上限时**主动收尾**：把手上的东西落到可交付状态，而不是留半成品

**反面案例**（原文）：

> task 3681 对 `Qt5::3DCore` 反复推演调参 3.5 小时**无一次阶段性上报**，直到预算耗尽。

**关键不是"不要超时"，而是"不要无上报地超时"。** 中途上报一次，别人就能介入。

## 2. 与止损配套的两条纪律

### 不裸等

需要等待外部结果（CI 跑完、别人回复）时：

- ❌ 不要空转轮询
- ✅ **先把当前可做的部分落下来**（提交、写文档、记录状态），再查结果

"等 CI"本身不是问题，"**什么都不做地等**"才是。

### 不盲目重推

失败原因不明时：

- ❌ 不要"改一点再推一次看会不会过"
- ✅ 先**诊断归类**：链接 / 编译 / 配置 / 依赖 / 权限 / 网络 / 文件缺失 / 测试空壳

本项目实测：60% 以上的 CI 失败属于**首次看日志时看不出原因**的类型。
本仓库已有多份诊断判据（章节边界、验证等级、权限缺失、编码），都是靠**读日志 + 归类**定位的，
不是靠重推。

---

## 3. 怎么判断"我该止损了"

自查清单（任一条为"是"就该停）：

- [ ] 我上一次的**观察结果**和这一次几乎一样吗？
- [ ] 我改的是**参数**，还是**手段**？
- [ ] 我能说清"这次为什么应该不一样"吗？说不清就是在赌
- [ ] 我已经连续失败几次了？数一下
- [ ] 如果我什么都不改，会有人/有机制告诉我方向错了吗？
- [ ] 我最近一次**阶段性结论**是什么时候？（超过 30 分钟没有 = 危险）

---

## 4. 这一条同样适用于人类

止损规则不是给 AI 定的特殊规则。
"再试一次就通了"是人和模型共有的认知偏差。
**区别只在于：模型更容易无限重试，因为它不会累。**
