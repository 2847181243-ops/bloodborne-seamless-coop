# docs/conflict_log/ —— 冲突记录与裁决

**所有者：AI-00（Integration Lead）**

---

## 1. 裁决规则（任务书 §49）

| 冲突类型 | 裁决方 | 优先级 |
|---|---|---|
| 接口冲突 | AI-00 | 开发优先 |
| 安全 vs 开发 | AI-C3 | **安全优先** |
| 性能 vs 安全 | AI-C2 | **安全优先** |
| 功能 vs 安全 | AI-C3 | **安全优先** |
| 版本兼容冲突 | AI-00 | 兼容优先 |

> **核心原则：安全永远优先。**
> 任何以“性能”或“功能”为由削弱安全的设计，必须建立 Issue，由 AI-C3 裁决。

---

## 3. 必须记录的情形

- 接口契约被单方面修改；
- 安全审计结论与开发进度冲突；
- 两个 Agent 对同一原版行为的逆向结论不一致；
- 需要跨所有权修改文件；
- 性能预算与安全约束不可兼得；
- 版本兼容性与功能实现冲突。

---

## 4. 记录纪律

- 裁决**必须留痕**，不允许口头 / 私聊结论直接生效；
- 安全类冲突在裁决完成前**保持阻断**；
- 裁决结论若改变了接口，必须同步更新 `docs/interfaces/`。
