## 引用格式

```text
<owner>/<repo>@<默认分支或提交>:<path>
```

例：`systemd/systemd@main:man/systemd.kill.xml`。

- 引用必须能实际打开并读到相应内容；只有二手博客或转述的不算来源。
- 正文不放大段原文（许可与体量两方面原因），只写读懂后的结论 + 关键词定位。

## 证据等级

| 等级 | 含义 |
|---|---|
| Confirmed | 实际读到一手文件，结论直接来自它 |
| Likely | 多份一手材料交叉推断，没有单点直接表述 |
| Unverified | 没找到一手来源，只作为待核对的问题 |

**只允许一手来源**（官方文档、规范、源码、设计文档）。找不到就写「未核实」，不用记忆补全。

## 维护规则

1. 新增条目：在 `docs/references/` 下建 `<主题>.md`，并在上表登记一行（ID 连续）。
2. 条目正文结构：结论摘要 → 逐条先例（做法 / 来源 / 对我们的映射：采用、暂缓或拒绝）→ 与我们的差异 → 未核实项。
3. 决策变更时更新条目的「对我们的映射」，在条目顶部写「最后更新」；**不要删除旧结论**，标明被谁取代。
4. 条目只记录外部先例与映射，不改写本项目的任何规范。
